                          現代化科技感視覺元素

┌─────────────────────────────────────────────────────────────────────────────┐
│ 元素        │ 實現方式                      │ 效果                           │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 漸變色      │ linear-gradient(135deg, ..)  │ 品牌色彩動態感                 │
│             │ --gx-gradient-primary        │                                │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 毛玻璃      │ background + backdrop-filter │ 現代科技感背景                 │
│ (Glass)     │ var(--gx-glass-bg/backdrop)  │                                │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 發光        │ box-shadow / text-shadow     │ 強調重點元素                   │
│ (Glow)      │ --gx-glow-primary/accent     │                                │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 陰影深度    │ --gx-shadow-xs/sm/md/lg/xl   │ 空間感層次                     │
│             │ 0 Xpx Ypx rgba(...)          │                                │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 動畫        │ @keyframes gx-fade/scale/... │ 平滑過渡與交互感               │
│             │ --gx-transition-normal/slow  │                                │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 深色模式    │ @media (prefers-color-scheme │ 智能適應系統設置               │
│             │ data-theme attribute         │                                │
├─────────────┼──────────────────────────────┼────────────────────────────────┤
│ 霓虹效果    │ border + glow + text-shadow  │ 賽博朋克風格                   │
│             │ transparent bg               │                                │
└─────────────┴──────────────────────────────┴────────────────────────────────┘
